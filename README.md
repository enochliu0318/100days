# Enoch & Sissi · 100 Days

纯静态网站,无需构建。内容全部放在 Markdown 文件里,改完 `git push` 即可更新。

## 目录结构

```
.
├─ README.md
├─ .gitignore
└─ public/                  ← 部署目录(Cloudflare 只发布这里)
   ├─ index.html            页面骨架
   ├─ css/style.css         样式(粉金主题,支持深色模式)
   ├─ js/
   │  ├─ app.js             主逻辑:密码锁、读取内容、计数器、三个视图、内容包渲染、情书弹窗
   │  ├─ md.js              Markdown 解析
   │  ├─ fx.js              花瓣、爱心、烟花特效
   │  ├─ music.js           背景音乐
   │  ├─ views/default.js   默认渲染器(信封 + 画框)—— 想自定义就整份复制走
   │  └─ milestones/        你自己的渲染器放这里(见该目录里的 README)
   ├─ content/              ← 日常只需要编辑这里
   │  ├─ site.md            名字、在一起的日期、里程碑列表、音乐路径
   │  ├─ timeline.md        回忆时间轴
   │  └─ milestones/        每个纪念日一个「内容包」,文件名就是天数
   │     ├─ 100.md          第 100 天:一封信 + 一幅画
   │     └─ 365.md          第 365 天(占位草稿,见下)
   └─ assets/
      ├─ music.mp3          背景音乐(自行放入,文件名与 site.md 中 music 一致)
      └─ photos/            时间轴照片
```

## 内容怎么改

- **site.md**:`him` / `her` 是两人名字,`start` 是在一起的日期(格式 `2026-06-30`),
  `milestones` 是**里程碑天数列表**(从小到大),`tease` 是提前多少天开始预告下一站,
  `showcase` 是纪念日前后各多少天把这一站浮到主页。
- **timeline.md**:每条记录以 `## 日期 | 标题` 开头,可写多段正文,也可插入照片,详见文件顶部说明。
- **milestones/`<天数>`.md**:一个纪念日一个文件,文件名就是天数。里面用
  `## 类型 | 标题 [| 图片路径]` 分段:`信` 会逐字显现、`画` 会装进画框可放大,想加什么加什么。

## 页面结构

进来是**主页**,顶部是一条 iOS 液态玻璃分段条:**时间轴 / 主页 / 纪念日**(主页在中间),
点它就能换页 —— 单页切换,一次只显示一页,切换时轻轻浮上来。

- **主页**:永远有计数与倒计时;到了**纪念日前后 `showcase` 天**(默认 7,即前后各一周),
  这一站的**内容包**会自己浮到主页 —— 信封能拆、画能放大,和以前一样。
- **时间轴**(主页左边):和你在一起的一个个瞬间。
- **纪念日**(主页右边):所有已到达的纪念日,一站一张卡;点开在下面展开这一站的内容包
  (再点一次同一张卡、或点详情下的「收起 ↑」即可收起),地址会变成 `#/milestones/100`,可以直接分享 / 收藏。

## 里程碑配置

配置在 `site.md`:

```yaml
milestones: 100, 365     # 里程碑天数,从小到大
tease: 30                # 提前多少天开始预告下一站(下一站的倒计时卡片这时才出现)
showcase: 7              # 纪念日前后各多少天,这一站浮到主页
```

一条规则:**一个天数 = 一站**。

- **最早那一站**(`milestones[0]`)解锁首批内容(信封 / 画 / 时间轴)。过了这天就**永久解锁**。
- **已经到达的每一站**,只要 `content/milestones/<天数>.md` 写好了(且没有 `draft: 1`),
  就永久待在「**纪念日**」页里;平时主页不打扰你,只有到纪念日前后才回主页做客。
- **还没到达的下一站**:计数器瞄准它(圆环 `/ 365 天`、距离倒计时),只在到达前 `tease` 天才预告。

### 往后延续

只要在 `milestones` 里加一个数字,再到 `content/milestones/` 放一份 `<天数>.md` 就行,
**不用改任何其它文件,也不用给已有文件改名**。例如明年再加一站:

```yaml
milestones: 100, 365, 730
```

然后放一份 `content/milestones/730.md`。纪念日页、计数器、「下一封信」都会自动跟着走。

### 一个纪念日怎么写

`content/milestones/<天数>.md` —— front matter 写这一站的说明,正文用 `##` 分段:

```markdown
---
title: 第一个一百天             # 卡片 / 小标题上的名字
desc: 我们在一起的第一个一百天    # 卡片上的一句话(可留空)
to: 写给最亲爱的宝宝             # 信纸开头的称呼(留空则用 "To my dearest Sissi,")
# draft: 1                      # 先放草稿不显示;删掉这行就开始展示
# view: 100                     # 想给这一站写自己的排版/动画,填个名字(见下)
---

## 信 | 写给宝宝的信
（这里写正文,会一句一句显现出来）

## 画 | 小海豚 ❤️ 小白鲸 | assets/photos/100天.jpg
（这一行会显示成画下面的题词）
```

- 类型写 `信` → 逐字显现的信(点信封拆开读);写 `画` / `图` → 上框的画(点开能放大)。
- 类型写别的(比如 `歌`、`诗`)→ 当成普通文字块排出来。
- 想加几块就加几块,写的顺序就是页面上的顺序。
- 图片放进 `public/assets/photos/`,路径写相对的 `assets/photos/文件名.jpg`。

### 想换一套排版 / 动画?

默认渲染器在 `js/views/default.js`(信封 + 画框),它只是"起手式"。
把整份复制到 `js/milestones/<名字>.js` 改一改,再到这一站的 front matter 里写 `view: <名字>`,
这一站就完全按你写的来 —— **数据(`ms.blocks`)和样子是分开的**,详见 `public/js/milestones/README.md`。

## 本地预览

页面通过 `fetch` 读取 md 文件,不能直接双击打开 `index.html`,需要起一个本地服务:

```bash
npx serve public
# 或
python3 -m http.server -d public 8000
```

## 部署到 Cloudflare Pages

1. 把仓库推送到 GitHub(或 GitLab)。
2. 进入 Cloudflare 控制台,新建 Pages 项目并连接该仓库。
3. 构建设置:Framework preset 选 `None`,Build command 留空,Build output directory 填 `public`。
4. 保存并部署。之后每次 `git push`,Cloudflare 都会自动重新发布。

控制台界面可能会有调整,但这三项设置的含义不变。也可以不用 Git 集成,直接用命令行部署:

```bash
npx wrangler pages deploy public --project-name enoch-sissi
```

## 注意事项

- **首页密码锁**:打开网站需先输入四位密码(提示"我们的第一天",默认密码 `0630`),每次刷新都要重新输入;进入后右上角 🔒 可再次锁定。电脑上可直接用键盘输入数字、按退格删除,手机上点圆点键盘。想改密码:改 `public/js/app.js` 里的 `const CODE='0630'`;想改提示语:改 `public/index.html` 里的"提示 · 我们的第一天"。
- **音乐**:请自行准备音频文件并命名为 `public/assets/music.mp3`。上传和公开播放受版权保护的歌曲前,请自行确认授权。文件不存在时,页面会播放内置的氛围音,右上角的"＋"按钮也可临时选择手机里的音频。
- **缓存**:md 文件已设置为每次重新校验,更新后刷新页面即可看到。照片和音乐可能被浏览器缓存,替换文件时建议换一个文件名。
- **字体**:标题字体来自 Google Fonts,加载失败时会自动使用系统字体。
